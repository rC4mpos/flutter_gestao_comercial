# flutter_gestao_comercial

Etapa 3 da apostila "Flutter do zero ao front-end completo": criação do projeto Flutter.

É o projeto padrão do Flutter: uma tela com um contador e um botão **+**.

## Como rodar

1. Abra esta pasta no VS Code (**File → Open Folder**).
2. Abra o terminal (**Terminal → New Terminal**).
3. Digite um comando de cada vez:

```
flutter pub get
flutter run -d chrome
```

O Chrome abre com o contador. Para encerrar, volte ao terminal e aperte `q`.

O código fica em `lib/main.dart`.
